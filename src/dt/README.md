# GNN-Based Digital Twin for RAN environmnet

Graph Neural Networks (GNNs) are one of the best ways to represent wireless networks due to their ability to effectively model complex network structures and interactions. In this project, we aim to create a virtual representation of the NS-O-RAN simulator as a physical twin using GNNs.

This Digital Twin will periodically collect KPI metrics from the Shared Data Layer (SDL) and provide an interface to access the latest network graph. By leveraging this approach, any AI-based solution can use the DT to obtain an up-to-date representation of the network, which can be used for tasks such as traffic steering, anomaly detection, and energy optimization.
